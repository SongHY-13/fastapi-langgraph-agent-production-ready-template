# 07：客户资料、协作接口与验收清单

更新日期：2026-11-03。客户功能覆盖小程序、平台后端及 AI 咨询后端；下表保留整套功能，便于分工与验收。首期 AI 后端负责问答、安全检查和风险信号。接口细节见 [v0.4 联调协议](08-miniprogram-mvp-api.md)，流程见 [工作流](../workflow.md)，检索见 [RAGFlow 接入](06-ragflow-integration.md)。

## 1. 逐项需求与责任

| 编号 | 客户功能 | AI 咨询后端 | 小程序与平台 | 验收场景 |
| --- | --- | --- | --- | --- |
| R01 | 全局悬浮窗 | 提供咨询接口 | 负责常驻、拖拽与记忆、半屏/全屏、最小化 | 切页、收起后可恢复对话 |
| R02 | 平台用户接入 | 验证平台调用与可信上下文 | 管理登录、用户、会话权限 | 篡改身份或会话关联不能越权；小程序不保存服务端密钥 |
| R03 | 多轮对话 | 利用约定上下文回答及澄清 | 维护用户会话、上下文与历史展示 | 连续追问语义一致，重试不重复追加 |
| R04 | 流式回复、停止、重新生成 | 输出经审核的流式事件；支持取消、重新生成 | 解析事件、显示状态、发起取消及重新生成 | 取消和完成竞态结果一致；重新生成与同请求重试可区分，不重复追加用户消息 |
| R05 | 输入与输出安全 | 识别违规意图，审核输入和输出 | 显示拒答与安全提示 | 科普求助不会因敏感词一律拒答；违法交易请求不输出可执行帮助 |
| R06 | 语音提问及播报 | 接收确认后的转写文本，走统一问答和安全流程 | 负责麦克风授权、录音上传、转写、低置信度降级、播报与停止播放 | 识别失败或低置信度时可切换或修订文字 |
| R07 | 戒毒知识问答 | 基于已审校证据回答，返回来源与适用提示 | 展示引用和已确认的科普提示 | 证据可核对；无证据不编造；医学高风险发独立信号 |
| R08 | 国家与江西政策法规 | 校验适用地区、日期和生效状态，返回名称、文号及出处 | 提供原文查看、人工或法律援助入口 | 失效政策不当作现行政策；超范围个案给出适当引导 |
| R09 | 办理流程问答 | 依据发布资料回答条件、材料、步骤、时限 | 提供现行流程和对应功能入口 | 信息不足先澄清；流程更新后不使用旧口径 |
| R10 | 场景跳转和功能卡片 | 返回平台允许的 action_code 和参数 | 提供动作字典、映射页面、执行权限、转化回传 | 生成内容不能指定任意路由；平台能统计点击和办理结果 |
| R11 | 转人工 | 识别显式请求；同一会话连续两次无法作答时返回普通建议，建议 advisory.code=human_handoff_suggested | 显示入口、接收确认、创建及受理工单，保存授权摘要，通知用户人工回复 | 两次无法作答显示建议；系统忙可返回普通错误；AI 建议不会被显示为工单已受理 |
| R12 | 高风险识别 | 在常规答复前识别并返回独立 human_handoff_required 信号 | 接收信号并按核定策略处置 | 多轮新信息可升级；高风险不混同普通人工建议 |
| R13 | 紧急处置和转介 | 提供审核过的风险提示及结构化风险信号 | 记录风险、按地区展示核验资源、派发转介单、通知工作人员和跟踪处置 | 高风险不等待普通提醒时限；工单失败不被显示为已受理 |
| R14 | 普通工单 24 小时未受理提醒 | 供平台关联咨询轮次和信号 | 负责持久化后台催办、状态、去重及重试；时限口径待确认 | 重启后可恢复；已受理不重复提醒 |
| R15 | 历史记录、留存、删除和隐私 | 遵循约定的必要上下文及运行数据处理范围 | 管理历史列表、详情、继续追问、删除、风险记录、加密和脱敏展示 | 跨用户隔离；删除和风险留存按平台获批规则执行 |
| R16 | 热门 FAQ、分类和联想 | 接收 FAQ 点击后送来的问题，按正常问答处理 | 负责 FAQ 的内容维护、发布、排序、联想和点击计数 | 未发布条目不展示；不将其他用户历史作为联想结果 |
| R17 | 评价、纠错和未解决反馈 | 提供可关联的回答和知识来源标识 | 负责赞踩、纠错、未解决反馈、处理状态和运营后台 | 同一反馈重试不重复；纠错不绕过专业审校 |
| R18 | 问答质量与知识运营 | 提供回答结果、引用与版本等可汇总信号 | 汇总回答率、满意率、人工转接率及未命中问题，组织审核更新 | 指标分母可复算；普通建议、风险信号、建单和受理分别统计 |
| R19 | 图片提问 | 首期接受约定的图片 URL 或 Base64，并纳入输入检查 | 负责选图、授权、上传或编码、展示失败原因 | URL 和 Base64 均可联调；不合规输入按约定拒绝，不进入常规生成 |

AI 后端不承接面向用户的历史管理、音频上传或转写、工单、通知、FAQ 和反馈接口。平台按合同向 AI 传入上下文，使用回答、引用和信号组织用户体验。生成任务所需的短期运行状态与平台长期业务历史分别约定。

## 2. 客户需提供的材料

| 材料 | 应包括 |
| --- | --- |
| 戒毒知识 | 正文、标题、来源、原文链接、日期、适用人群、专业审校人与禁用范围 |
| 国家与江西政策 | 名称、文号、发布机关、正式正文和官方解读、发布/生效/失效日期、地域、替代关系、发布状态和维护人 |
| 办理流程 | 业务编号、对象、前置条件、所需材料、步骤、时限、渠道、例外、版本和平台动作关联 |
| FAQ 与样例 | 问题、分类、别名、发布顺序、经审校答案和出处；覆盖追问、无答案、违规、高风险、人工请求与图片的验收样例 |
| 知识运营 | 内容审校人、发布与撤回流程、复核周期、失效通知和纠错责任人 |
| 风险与紧急资源 | 分级、命中样例、审核话术、经客户核验的地区资源、适用人群/场景、有效期、维护人及升级策略 |
| 客服处置 | 受理团队、排班、时限口径、普通催办及高风险升级、人工回复和用户通知机制 |
| 隐私与留存 | 平台确认普通及高风险记录是否保留、期限、删除限制和解除权限；确定未成年人处置、通知、数据访问和审计责任。早期草案中的高风险会话不可删除不视为当前已确认规则 |
| 质量目标 | 覆盖、引用质量、风险误判/漏判、延迟、并发、可用性和统计周期；由双方确认验收阈值 |

可先用虚构测试材料、模拟风险信号与示例动作字典验证接口；正式知识发布、对外提示话术和真实处置由客户核验后配置。

## 3. 小程序与平台同事需提供的接口和规则

| 合同 | 首轮要确认的内容 |
| --- | --- |
| 服务调用和用户身份 | 同机回环直连，平台校验会话归属并写入可信用户标识，验证测试环境和越权错误码 |
| 多轮与历史 | 会话/轮次 ID、上下文传入边界、大小上限、可信消息角色、归属校验、历史与删除责任 |
| 流式、停止与重试 | 网关分帧、缓冲、心跳、断线和重连；业务取消和停止传输的区别；重试复用幂等键，重新生成使用新任务并关联原问题 |
| 图片 | URL 允许域、地址有效期和服务访问授权，按可信主体及 `file_id` 读取原文件的方式，Base64 格式、大小和失败约定 |
| 语音 | 小程序录音上传方式、平台 ASR/TTS 归属、低置信度规则；AI 接收已确认文本 |
| 来源和动作 | 引用打开方式、官方链接/附件访问、action_code 字典、参数和权限、实际页面映射及业务来源标记 |
| 风险信号与转接 | 普通 advisory、高风险 human_handoff_required 的接收与展示；平台工单、重复派单防护、受理、通知和失败兜底 |
| FAQ、反馈与统计 | 现有平台接口或负责方，回答/知识版本关联键；曝光、点击、到达和办理事件定义；分母及去重方式 |

建议按同会话连续两轮业务无法作答提供普通建议；有效回答后清零。澄清、合规拒答、业务完成前取消和高风险独立信号不计入；系统忙等依赖故障可走正常错误，是否计入需双方另行确认，不默认按无法作答处理。生成终态与传输状态分别记录：审核结果已落库后停止传输，不将已完成改为取消，也不撤销已经提交的风险信号。

## 4. 分阶段验收

| 阶段 | AI 侧验收 | 平台协作验收 |
| --- | --- | --- |
| A：合同与模拟联调 | 文本、图片 URL/Base64、上下文、引用、事件、取消、重新生成、普通建议和风险信号可用样例验证 | 回环转发、会话关联、状态映射及真机分块读取，使用合成数据验证 |
| B：问答与安全 | 三类知识的来源真实、适用、可核对；未命中或失效不编造；正常科普与违规意图可区分 | 引用可打开，功能卡片按权限跳转，语音转写及降级走平台 |
| C：人工与风险 | 两轮无答案建议与高风险独立信号可区分；正常系统错误不假称已转人工 | 人工建单、回执、24 小时提醒、紧急处置和通知在平台闭环；使用核验资源与明确策略 |
| D：历史与运营 | 返回可关联的回答状态及版本 | 历史、留存/删除、FAQ、反馈、转化和质量指标由平台验证，客户确认运营及留存规则 |

给客户优先索取：三类审校材料和出处、标准问答与反例、风险规则和核验资源、客服处置机制、留存与隐私要求。给小程序/平台同事优先索取：用户标识与会话示例、流式和停止/重试行为、图片和转写协议、动作字典、信号处理与工单归属、历史和运营接口。

小程序预开发可直接使用 [v0.4 协议和 mock](08-miniprogram-mvp-api.md)。真实环境验收待平台提供真机和转介样例，并使用客户批准的知识与风险策略。验收结果集中记录于 [研发交接](04-handoff.md)。
