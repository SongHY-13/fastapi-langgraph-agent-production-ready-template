## 本次文档修订的主要决定

1. LangGraph 保持主编排，RAGFlow 作为受控检索工具；领域事实问题必须检索，首版不以开放搜索代替权威资料。
2. 风险识别前置，紧急提示和可靠工单分别处理；普通 24 小时提醒不能用于高风险兜底。
3. 首版采用完整候选审核后分段发送，提供独立取消与可查询任务状态；首字延迟需产品确认。
4. 功能跳转使用平台能力编码，来源使用真实文档/片段映射；两者都不让模型自由编造。
5. 历史/反馈/工单使用业务记录，checkpoint 负责执行恢复；高风险锁定依据和保留期限由客户确认。
