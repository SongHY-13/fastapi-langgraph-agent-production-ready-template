## 先理解这几个名词

| 名词 | 在本项目中的作用 |
| --- | --- |
| FastAPI | 接收 HTTP 请求、校验参数、鉴权，再把工作交给业务服务 |
| LangGraph | 用“状态 + 节点 + 路由”组织多步对话流程 |
| LangChain | 消息、模型、工具调用的统一接口 |
| Checkpoint | 保存一次会话的图状态，用于继续聊天和中断恢复 |
| mem0 | 从对话中提取长期记忆，按用户检索；它也会调用模型和 embedding |
| Langfuse | 跟踪模型调用和评估数据；需要明确哪些内容可以被记录 |
| SSE | 服务端持续向前端发送文本事件的 HTTP 流式响应 |
| PII | 能识别个人身份的信息，例如姓名、手机号、证件号码及可关联的组合信息 |

## 需要提前知道的三个事实

1. `sanitize_string()` 做的是 HTML 等输入清理，不会把个人信息匿名化。
2. 原文可能经过标题生成、记忆检索、checkpoint、日志和追踪等多条路径。只在主模型调用前替换姓名，无法覆盖这些路径。
3. 占位符替换与加密不同；有还原表的方案属于可逆化名化，需要单独保护还原表和还原权限。
